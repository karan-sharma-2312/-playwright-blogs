# Playwright Blog on GitHub Pages

This repository hosts a static technical blog focused on Playwright with Python in VS Code.

## Purpose

The blog documents a practical learning journey in two stages:

- Day 1: Playwright installation and environment verification
- Day 2: Assertion-based testing and HTML report generation

## Repository Contents

- index.html: Main blog page with Day 1 and Day 2 sections
- playwright-report-reference.png: Screenshot reference of the generated pytest HTML report
- README.md: Project and publishing instructions

## Local Preview

1. Clone the repository:

```bash
git clone https://github.com/karan-sharma-2312/-playwright-blogs.git
```

2. Open the repository in VS Code.
3. Open index.html in your browser, or run a local static server for preview.

## Publish with GitHub Pages

1. Push all blog files to the main branch.
2. Open repository Settings, then Pages.
3. Set Source to Deploy from a branch.
4. Select Branch main and Folder /(root).
5. Save and wait for deployment.


Current repository URL :

https://karan-sharma-2312.github.io/-playwright-blogs/

## Update Workflow

1. Edit index.html with new content.
2. Commit and push changes.
3. Refresh the live page after deployment completes.

## Notes

- GitHub Pages updates usually appear within a few minutes.
- Keep file paths relative so images and assets load correctly on the live site.
