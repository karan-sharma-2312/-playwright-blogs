# Playwright Blog on GitHub Pages

This repository hosts a static technical blog focused on Playwright with Python in VS Code.

## Purpose

The blog documents a practical learning journey in Playwrite.

## Repository Contents

- index.html: Main blog page with Day 1 and Day 2 sections
- playwright-report-reference.png: Screenshot reference of the generated pytest HTML report


## Local Preview

1. Clone the repository:

```bash
git clone https://github.com/karan-sharma-2312/-playwright-blogs.git
```


## Publish with GitHub Pages

1. Push all blog files to the main branch.
2. Open repository Settings, then Pages.
3. Set Source to Deploy from a branch.
4. Select Branch main and Folder /(root).
5. Save and wait for deployment.
